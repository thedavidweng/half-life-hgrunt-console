## for-of 的 no-unused-vars 误报：已根治（非靠 disable 注释）

**根因**：CRA 构建用 eslint-loader（`useEslintrc: false`，所以 package.json 的 eslintConfig **在构建时无效**），parser 由 `eslint-config-react-app@5.0.1` 指定为 `babel-eslint`。而 **react-scripts 内部嵌套了自己的 `babel-eslint@10.0.2`**，ESLint 相对 config 文件位置解析 parser，命中这份嵌套副本。10.0.2 会把 `for...of` 的循环变量误报为 unused。

**关键调试技巧**：
- `node -e "require.resolve('babel-eslint', {paths:[require('path').dirname(<config-index.js>)]})"` —— 查出 ESLint **实际**加载的是哪一份（根目录装新版没用，就是这么发现的）
- `find node_modules -maxdepth 4 -name babel-eslint -type d` —— 列出所有副本

**对照实验**（最小复现 + 换 parser，用 `CLIEngine` + `baseConfig.extends=[eslint-config-react-app]` + `resolvePluginsRelativeTo`）：

| parser | 误报 |
|---|---|
| babel-eslint 10.0.2 | 1 |
| **babel-eslint 10.1.0** | **0** |
| @babel/eslint-parser 7.28 | 0 |
| espree（ESLint 内置） | 0 |

**修法**：package.json 加 `"overrides": {"babel-eslint": "^10.1.0"}`（+ `resolutions` 兼容 yarn）。npm 安装后嵌套副本被去重消除，解析到根目录的 10.1.0。已删除 `src/hgrunt.js` 里全部 3 条 disable 注释，CI=true 构建零告警，GitHub Actions 全新安装同样通过。

**踩坑**：`npm install`（npm 7+）会**顺手重写 yarn.lock** —— 格式从 yarn 风格变 npm 风格，还把整棵依赖树从锁定版本刷新到最新（@babel/code-frame 7.5.5 → 7.29.7），产生 9000+ 行无关 churn。已 `git checkout -- yarn.lock` 回退。本仓库 yarn.lock 是被跟踪的，跑完 npm 命令要检查它是否被改动。

## 后续调整（08-28 15:08）

- **问题 1：点选 tag 时不该出现候选词列表（因为没在输入）**
  - 把 `minQueryLength` 从 `0` 改成 `1`，只有真正输入时才展示建议；同时新增 `handleInputChange`，一旦用户开始输入就自动清除当前 tag 选中态。
- **问题 2：拖拽时插入位置不够清晰**
  - `react-tag-input` 在拖拽时会把被拖 tag 的 DOM 透明度设为 0，并实时重排 tags。我们在 CSS 里把这个隐藏的 tag 强制显示为「虚线幽灵」占位，并在左侧加一条白色竖线（`box-shadow: -2px 0 0 ...`，无布局位移），标示它即将插入的位置。
  - 为 `.ReactTags__tag` 加了 `position: relative` 作为阴影定位基准。
- **问题 3（关键坑）：拖拽占位标记只在原始位置出现，移动后消失**
  - 根因：`ReactTags.getTagItems()` 的 key 是 `tag.id + '-' + index`。一旦重排，所有 key 全变 → 每个 tag 组件**全部卸载重建** → 正在拖的那个 DOM 节点被销毁，react-dnd 的 `isDragging` 丢失，再也没有元素带 `opacity: 0`，依赖内联样式的 CSS 选择器（`.tag-wrapper[style*="opacity: 0"]`）自然全部失配。
  - 解法：不依赖库的 `isDragging`，改为在 App 里自己追踪「被拖词当前下标」`dragIndex`：
    - `dragstart`（document 级）时用 `closest('.ReactTags__tag')` + `querySelectorAll` 求出原始下标；
    - `handleDrag(tag, currPos, newPos)` 里把 `dragIndex` 更新为 `newPos`；
    - `dragend` / `drop`（都挂 document，因为源节点中途已被移除，事件可能不会冒泡经过 wrapper）时置回 null；
    - render 时给该下标的 tag 加 `className: 'ReactTags__tag--dragging'`，CSS 用这个 class 画虚线幽灵 + 左侧白线。
