# Half-Life HECU Grunt Console

This is a website where you can make Half-Life's HECU Marine (Human Grunt) say stuff. All the voice lines from the game are chopped up and you can write them out in whatever sequence you want.

Check it out at https://thedavidweng.github.io/half-life-hgrunt-console
